# ZenDesk Pro 

A futuristic, cyberpunk-themed personal dashboard application with an animated aurora background and a "glassmorphism" aesthetic. This project is built with vanilla HTML, CSS, and JavaScript, focusing on modern UI design and dynamic, client-side functionality.

## ✨ Features

- **Animated Aurora Background:** A dynamic, generative background of colorful, glowing particles.
- **Multi-User Authentication:**
  - Secure signup with name, email, and password.
  - Login system with password validation.
  - User-specific data storage for tasks and notes using browser `localStorage`.
- **Progressive Signup Form:** A slick, animated signup form that reveals fields as you interact with it.
- **Task Manager:** Add, complete, and delete tasks with different priority levels (Low, Medium, High).
- **Quick Notes:** A simple notepad to quickly jot down and save notes.
- **Pomodoro Timer:** A built-in 25-minute timer with start, pause, and reset controls.
- **Dynamic Widgets:**
  - **Weather:** Displays the current temperature and location (defaults to Delhi, IN).
  - **Quote of the Day:** Shows an inspiring quote on every session.
- **Quick Links:** A customizable section for frequently visited websites.
- **Fully Responsive:** The interface is designed to adapt to various screen sizes, from mobile devices to desktops.

## 🛠️ Tech Stack

- **HTML5:** For the core structure and content.
- **CSS3:** For styling, layout, and animations.
  - **Flexbox & Grid:** For modern, responsive layouts.
  - **Custom Properties:** For a maintainable and themeable color palette.
  - **Keyframe Animations:** For UI effects and transitions.
- **JavaScript (ES6+):** For all client-side logic, including authentication, state management, DOM manipulation, and dynamic widget functionality.

## 🚀 How to Use

This project does not require any installation or build steps.

1.  Clone or download the repository.
2.  Open the `index.html` file in any modern web browser (e.g., Chrome, Firefox, Edge).

That's it! You can now create an account and start using your personal dashboard.
